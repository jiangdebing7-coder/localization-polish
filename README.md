# 本地化润色（localization-polish）

Cindy 插件，用于润色和审校游戏、应用、产品及 UI 的现有译文。支持任意语言组合、多目标语言和地区变体，不限中英。润色由 Cindy Agent 直接完成；占位符核验工具只是可选辅助。润色优先遵循目标语言的表达习惯；描述性文案可重组和意译，避免逐句直译与机翻感。

默认逐条输出 **原文 / 译文 / 优化后译文 / 修改原因** 四列，单条和批量任务均适用，方便人工验收，无需另行要求对照表。

## 能力

- 按目标语言习惯重写句式、语序和表达；描述性文案不拘泥原文结构，同时保留事实、承诺、限制和关键信息。
- 对照原文核实语义与信息；仅有译文时改善自然度，不声称已验证准确性。
- 遵循术语表、风格指南、产品上下文及平台字数限制。
- 保护占位符、标签、URL、资源键和原有结构，并可逐字核对指定的固定片段。
- 在 Cindy 中使用 `$本地化润色`，或直接请求润色/审校现有译文。

## 安装

下载 [localization-polish-1.0.6.cindy](dist/localization-polish-1.0.6.cindy)，然后在 Cindy 的插件页面导入安装。也可以从源码目录使用 Cindy 官方 `ghost_forge_pack` 校验并生成安装包。不要仅将目录压缩并改扩展名：ZIP 完整性检查不能发现插件清单字段超限等安装错误。

注意：历史版本 `1.0.5` 的清单字段超长，会被安装器拒绝，请使用 `1.0.6` 或更新版本。

## 使用示例

> 用美式英语润色下列游戏对白，保留角色克制的语气、ID 和占位符。

> 对照中文审校这份多语言表格，按 ID 配对；输出原文、译文、优化后译文、修改原因，附带 ID。准确自然的条目保持不变。

尽量提供原文、现译及已有术语；有角色背景、地区或长度限制时一并提供。只有译文也可润色，但不能据此验证原文含义或漏译。

## 默认验收格式

| 原文 | 译文 | 优化后译文 | 修改原因 |
| --- | --- | --- | --- |
| 保存更改？ | Save changes? | Save changes? | 无需修改：表达准确、简洁，符合常见 UI 用语。 |

第四列必须写入最终文件的同一张主表，每条已修改记录填写 `“原措辞” → “新措辞”：具体原因`，多处改动逐项说明；未改记录填写“无需修改”。不能用整体总结、聊天说明或批注代替。导出后须重新读取实际文件，逐行检查四列及原因完整性。

原文和修改前译文保持原样；无需修改的条目也完整保留并解释原因。缺失原文时填写“未提供”，不反推。已有 ID 等元数据作为附加列保留，多目标语言分别提供验收表。默认在对话中给表格；要求 JSON、CSV 或 Excel 时仍保留四个核心字段，除非你明确指定其他模板或只要优化后的译文。

升级时请重新导入新版安装包，并确认插件版本为 **1.0.6**；仓库更新不会自动替换本机已安装的旧包。

## 隐私与边界

插件不调用外部翻译服务，也不自行上传用户文本。语言处理由当前 Cindy Agent 根据对话上下文完成；固定片段检查仅比较明确指定的文本片段，不代表翻译准确性验证。
