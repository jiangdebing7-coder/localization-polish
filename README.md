# 本地化润色（localization-polish）

Cindy 插件，用于润色和审校游戏、应用、产品及 UI 的现有译文。支持任意语言组合、多目标语言和地区变体，不限中英。

## 能力

- 对照原文检查含义、信息完整性、语气与自然度；仅有译文时只润色表达，不声称已验证准确性。
- 遵循术语表、风格指南、产品上下文及平台字数限制。
- 保护占位符、标签、URL、资源键和原有结构，并可逐字核对指定的固定片段。
- 在 Cindy 中使用 `$本地化润色`，或直接请求润色/审校现有译文。

## 安装

在 GitHub 仓库的 `dist/` 中下载最新 `.cindy` 包，然后在 Cindy 的插件页面导入安装。也可以从源码目录使用 Cindy 的插件打包流程生成安装包。

## 隐私与边界

插件不调用外部翻译服务，也不自行上传用户文本。语言处理由当前 Cindy Agent 根据对话上下文完成；固定片段检查仅比较明确指定的文本片段，不代表翻译准确性验证。
